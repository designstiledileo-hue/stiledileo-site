# STILE DI LEO — PROJECT PHOTO CAPTURE CHECKLIST v1.0

Use this checklist before, during, and after each publishable project.

The goal is proof quality, not volume.

## Before

Capture before any work begins:

- straight-on wide
- angled wide
- room context
- problem/detail close-up
- vertical phone shot for GBP/social

## Process

Capture only when practical and safe:

- original substrate
- masking/protection
- preparation
- mesh if used
- base coat
- primer
- leveling/substrate preparation
- intermediate stage
- finish application
- vertical process shot for social/story use

## After

Capture after completion:

- same angle as BEFORE where possible
- straight-on hero
- angled hero
- room context
- texture/detail close-up
- edge/detail transition
- lighting variation if useful
- vertical final shot for GBP/social

## Before/After Consistency

Whenever possible, match:

- camera position
- camera height
- lens/zoom
- framing
- orientation
- lighting direction

This makes transformation proof clearer and more credible.

## Authenticity Rules

Allowed:

- crop
- exposure correction
- white balance correction
- mild perspective correction
- compression
- resizing
- privacy redaction where needed

Prohibited:

- AI regeneration of project photos
- generative fill changing architecture
- removing fireplace projections
- adding/removing mantel geometry
- altering arch/opening geometry
- replacing surface geometry
- fabricating finished texture
- substituting another project
- fake before/after

## Asset Preservation

Keep separate:

- MASTER ORIGINAL
- WEB DERIVATIVE
- GBP DERIVATIVE
- SOCIAL DERIVATIVE

Never overwrite original customer/project photography.

## Suggested Future Filename Standard

Use lowercase, descriptive, project-specific filenames:

- `stile-di-leo-brookswood-fireplace-before-01.jpg`
- `stile-di-leo-brookswood-fireplace-mesh-01.jpg`
- `stile-di-leo-brookswood-fireplace-base-coat-01.jpg`
- `stile-di-leo-brookswood-marmorino-process-01.jpg`
- `stile-di-leo-brookswood-marmorino-after-01.jpg`
- `stile-di-leo-brookswood-marmorino-detail-01.jpg`

Do not rename existing production assets automatically.
