# STILE DI LEO — REVIEW REQUEST OPERATING PROCEDURE v1.0

## Purpose

Create consistent, legitimate Google review velocity from real completed customers without pressure, incentives, review-gating, or fake activity.

## Ethical Rules

Do not:

- buy reviews;
- incentivize reviews improperly;
- fabricate customers;
- create fake reviews;
- review-gate;
- ask non-customers;
- request a specific star rating.

Ask only legitimate completed customers who can honestly comment on the work.

## Trigger

PROJECT COMPLETED
→ customer confirms satisfaction
→ wait approximately 2–3 days
→ send review request
→ if no response, send one polite follow-up approximately 5–7 days later
→ stop

## Tracking

Track monthly:

- requests sent
- reviews received
- review conversion rate
- net new reviews during sprint

Suggested place to track:

- `SEO/STILE-DI-LEO-30-DAY-REVENUE-SCOREBOARD-v1.0.csv`
- lead/project register notes where useful

## Human Approval Gate

No review request should be sent automatically.

Before sending, confirm:

- the project is complete;
- the customer is legitimate;
- the customer has confirmed satisfaction or there is no unresolved issue;
- the direct Google review link is correct;
- the owner approves sending.
