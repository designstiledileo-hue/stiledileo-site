# STILE DI LEO — PROJECT CASE STUDY TEMPLATE v1.0

Use this template only with verified project facts and approved real project photography.

Do not publish a case study unless the minimum evidence gate is met:

- one verified BEFORE image
- one verified AFTER image
- verified project facts
- publication permission

## Metadata Drafting Rules

- Do not create generic competing owner-page titles.
- Do not replace the Fireplace Transformations or Marmorino owner pages.
- Keep the case study proof-led and local/project-specific.
- Mark unknown facts as `UNKNOWN` or leave them out.

- verified BEFORE image
- verified AFTER image

## 3. The Client's Problem

Use 1 short factual paragraph.

Include:

- original condition
- practical/aesthetic problem
- customer goal

Do not invent emotion, budget, timeline pressure, or quotes.

## 4. Before

Describe only what is visible and verified.

Include:

- surface type
- condition
- design issue being solved

## 5. Preparation

Include only verified preparation steps.

Possible verified steps:

- mesh
- base coat
- primer
- leveling
- substrate preparation

Do not imply every project uses every step.

## 6. Finish

Describe the verified material and visual direction.

Avoid unsupported durability or maintenance claims.

## 7. Process Proof

Use real process photography if available:

- substrate
- mesh
- base coat
- primer
- leveling
- finish application

## 8. After

Use the strongest final photography:

- straight-on hero
- angled hero
- room context

## 9. Detail

Show:

- texture
- movement
- material detail
- transitions/edges where useful

## 10. Result

Short factual transformation summary.

Example structure:

`The dated [verified original surface] was transformed into a [verified finish/material] fireplace surface after [verified preparation].`

## Copy Limits

Target length:

- approximately 400–800 useful words

Avoid:

- generic SEO filler
- repetitive location mentions
- keyword stuffing
- fake storytelling
- invented homeowner emotions
- unsupported product claims
- fabricated testimonials
- fabricated before/after descriptions
