# Application Intent & Site Architecture Audit v1.0

## A. Executive Summary
Stile di Leo has a strong material-led architecture, but the highest commercial clarity comes from application-led pages where homeowners understand the transformation before they understand the finish name.

Current architecture already supports three proven application paths:

- Fireplace transformations: strongest commercial application cluster, supported by Brookswood and West Vancouver project proof.
- Feature walls: broad, commercially useful cluster, supported by service pages and the sculpted architectural stone case study.
- Bathrooms / wet-area surfaces: commercially attractive but must be handled carefully because waterproofing, shower use, substrate, and system claims require verified capability.

The site should not chase every material keyword as a standalone service. The best next architecture move is to reinforce application clusters that can be sold responsibly today, while treating less-proven materials as sections, guides, or future validation topics.

## H. Application Cluster Analysis

### A. Fireplace Transformations
This is the strongest application cluster. It has commercial clarity, real project proof, homeowner relevance, and strong conversion fit. The current architecture teaches that application-first pages work when they connect visible transformation, material choice, pricing context, and photo-based consultation.

Recommendation: KEEP and EXPAND through project proof, not through thin keyword pages.

### B. Bathroom / Wet Areas
This cluster has strong commercial potential because homeowners search by application before material. Public SERP sampling shows competitors presenting microcement bathrooms, showers, kitchens, and wet rooms as commercial services. However, Stile di Leo should not publish shower or waterproof claims without verified system capability and project proof.

Recommendation: VALIDATE / EXPAND. Strengthen existing Microcement and Venetian Plaster Bathroom pages carefully before creating a wet-area owner page.

### C. Feature Walls
Current Feature Wall ownership is useful but broad. It can absorb Venetian plaster wall, Marmorino wall, lime plaster wall, metallic finish, and sculpted surface inspiration without spinning each into a page. The Projects hub and Sculpted Stone case study improve proof.

Recommendation: KEEP. Avoid creating many separate wall-finish pages until project proof and intent separation are clear.

### D. Kitchen Surfaces
Kitchen hood, backsplash, and countertop searches are not the same intent. Countertops require durability, food/contact, sealing, heat, impact, cleaning, and system claims. Hoods and backsplashes are decorative architectural surfaces with different expectations.

Recommendation: WATCH / VALIDATE. Do not create owner pages before proof.

### E. Sculptural Architectural Surfaces
The sculpted stone project is compelling but represents one custom project. It supports custom feature-wall capability, not a broad sculpted stone service line yet.

Recommendation: VALIDATE. Keep as project proof and observe demand before owner page.
